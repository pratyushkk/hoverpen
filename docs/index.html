Step-by-Step Installation & Setup

Three quick steps to install and activate WordPilot v2.0 on any modern Android device.

1

Install WordPilot v2.0 APK

Download the release APK WordPilot-v2.0.apk and tap to install on your Android device (Android 8.0 through Android 15/16).

Download v2.0 APK (12.9 MB) Download v1.0 APK (12.3 MB) All Releases
2

Enable Accessibility Service

Open WordPilot ➔ tap "Floating Assistant (Cross-App)" ➔ select "Open Accessibility Settings" ➔ tap WordPilot Assistant under Downloaded Apps and toggle to ON.

💡 HyperOS / ColorOS Note: If Android displays "Restricted setting", go to Phone Settings ➔ Apps ➔ WordPilot ➔ tap 3 dots (upper right) ➔ tap "Allow restricted settings", then re-toggle.
3

Configure Gemini Key & Tone Preferences

In API Providers & Keys or directly from the expander overlay, enter your Google Gemini API key to unlock real-time AI rewrites, or enjoy LanguageTool out of the box with zero configuration!
